# AI usage

What the AI generated in each phase, and what I changed or rejected. I fill in the second part when I review each pull request.

I kept my own prompts in `docs/prompt-log.md`.

## How the AI was used

- **Agent:** Claude Code, running on its own toward a stated goal, with two conditions under which it had to stop and wait for me.
- **Context I maintained:** `CLAUDE.md` for this repository, my global `CLAUDE.md`, and my own skills for project structure, TypeScript style, testing, documentation and writing.
- **Decisions:** real trade-offs went to a council of three advisors and a chair. Each verdict is recorded in an ADR, marked provisional until I confirm it.
- **Review:** one pull request per phase. I merge, nobody else.

## Phase 0: scaffold

### Generated by the AI

- The repository layout, `.gitattributes`, `.gitignore`, the Compose file for development and the three Dockerfiles.
- The Rails app, through `rails new` in a container. The AI then edited `database.yml`, `application.rb`, the development and production environment files and `test_helper.rb`.
- `lib/database_grants.rb` and its rake task, which hold the least-privilege policy.
- The first migration, for the nonce table.
- The handlers skeleton: the Node adapter, the router, the env schema, the query helper and the health endpoint.
- The web shell and the Playwright smoke test.
- The CI workflow.
- Five ADRs, the design note, the bug log and the environment reference.

### Decisions the AI took without me

| Decision | Why | Where |
|---|---|---|
| Pinned TypeScript 6.0.3, not 7.0.2 | `typescript-eslint` accepts only versions below 6.1.0 | design note |
| Moved three packages to older versions | The newest ones were published 4 to 24 hours earlier, and pnpm's release-age guard had flagged them | `CLAUDE.md`, gotchas |
| Denied every dependency install script | Each package ships its binary prebuilt. The tests pass without the scripts | `pnpm-workspace.yaml` |
| Ran two council decisions, not four | The goal was set seven hours late | design note |
| Brought one migration forward from Phase 1 | MySQL rejects a grant on a table that does not exist | ADR 004 |
| Did not create `.env.example` | My settings deny writes to that path | `docs/env-reference.md` |
